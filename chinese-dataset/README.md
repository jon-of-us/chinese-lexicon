# Chinese learning dataset

A curated set of Chinese dictionary, character, frequency, and audio data for learning Mandarin. The app reads this folder directly. The data is maintained by hand and is not generated by scripts. The full dataset (including audio) is kept locally, so only the JSON and the files listed here are tracked in git.

Status: draft, version 0.1.0.

## Layout

```
chinese-dataset/
  manifest.yaml              Interface: every file, its sources, count, and fields
  sources.json               Source registry: license, attribution, publishable flag
  dictionary/
    entries.json             Dictionary entries (CC-CEDICT + Dong Chinese statistics)
    index.json               Lookup maps from simplified/traditional keys to entries
    etymology.json           Character etymology and components
  frequency/
    character-order.json     First 1000 characters in learning order
    words.json               Top 2000 words by media frequency
    characters.json          Characters in those words, ranked by media frequency
  word-audio/
    hsk-words/               Native MP3s of HSK words, cmn-<text>.mp3
    syllables/               Native MP3s of readings, cmn-<pinyin>.mp3
    ATTRIBUTION.md           Speaker credits and licenses
  sentences/
    hsk-sentences-audio/     Sentences and audio, one folder per set
    tatoeba-nc/              Tatoeba sentences with CC BY-NC 4.0 audio
    tatoeba-unlicensed/      Ignored by git (see below)
    anki-tatoeba/            Ignored by git (see below)
```

Every JSON file starts with a `sources` array of source keys. Each key resolves in `sources.json`. Audio paths are relative to the folder holding the JSON.

## Files

| File | Contents | Count |
| --- | --- | --- |
| `dictionary/entries.json` | Entries with simplified, traditional, pinyin, definitions, statistics, and usage as a component | 124,774 |
| `dictionary/index.json` | Simplified keys (121,015) and traditional keys (122,197) mapped to entry positions | |
| `dictionary/etymology.json` | Character notes, definitions, components, and pinyin. No images | 5,088 |
| `frequency/character-order.json` | Characters in learning order | 1,000 |
| `frequency/words.json` | Words with translation, rank, and frequency | 2,000 |
| `frequency/characters.json` | Characters with media frequency and best word rank | 1,229 |
| `word-audio/hsk-words/` | Word MP3s | 8,596 |
| `word-audio/syllables/` | Reading MP3s | 1,707 |
| `sentences/hsk-sentences-audio/` | Sentence records with one MP3 each | 4,329 |
| `sentences/tatoeba-nc/` | Sentence records with CC BY-NC 4.0 audio | 30 |
| `sentences/tatoeba-unlicensed/` | Sentence records with no audio license in the export | 536 |
| `sentences/anki-tatoeba/` | Sentence records from an Anki shared deck, with Tatoeba duplicates removed | 737 |

Each sentence record has an `id`, `audio` (with `path`), `transcription`, `translation`, `word_split`, and `source_metadata`. HSK records also have `pinyin`. Tatoeba records include `audio_user` for crediting the uploader.

## Sources and licensing

Sources are defined in `sources.json`. Attribution text for each source is in its `attribution` field.

| Key | Used by | License | Publishable |
| --- | --- | --- | --- |
| `cc-cedict` | Dictionary, frequency words | CC BY-SA 4.0 | yes |
| `dong-chinese` | Dictionary, etymology, frequency | CC BY-SA 4.0 (owner-stated) | yes |
| `audio-cmn` | Word and syllable audio | CC BY-SA 4.0 | yes |
| `hsk-sentences-audio` | HSK sentences | CC BY-SA 4.0 | yes |
| `tatoeba-nc` | Tatoeba sentences with NC audio | CC BY-NC 4.0 | yes, non-commercial only |
| `tatoeba-unlicensed` | Tatoeba sentences, no license | unknown | no |
| `anki-tatoeba` | Anki deck sentences | personal study only | no |

## What is in git

Git ignores all MP3 files (`*.mp3` in the root `.gitignore`). The generated JSON files in `sentences/hsk-sentences-audio/` and `sentences/tatoeba-nc/` are not ignored, but audio is not committed. Recreate the audio locally before using the dataset. The two non-publishable sets are also ignored by folder name: `sentences/tatoeba-unlicensed/` and `sentences/anki-tatoeba/`. Do not publish them.

## Maintenance

The files are edited by hand. Nothing in this repository regenerates them. Changes are made directly in the JSON, and the manifest is updated in the same change.

## Known gaps

- `frequency/character-order.json` has no generator. Its origin is undocumented.
- 50 dictionary entries come only from Dong Chinese. They have no `pinyinTones` field.
- The source of the HSK sentence text (`hsk-sentences-audio`) is not verified.
- Whether the Tatoeba sentence text is licensed for publication is not verified.
- Images are not included. The app does not use them.
